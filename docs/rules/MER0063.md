# MER0063

## Summary

`MER0063` flags locally authored C# declaration names that contain a configured forbidden word. Each diagnostic creates a review point for the declaration's meaning, owner, and structure.

## Configuration

The consuming project supplies the vocabulary through `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.MER0063.severity = warning
meridian_forbidden_identifier_words = resolve|resolved|prepare|prepared
```

The value is pipe-separated. Parsing trims surrounding spaces, removes empty entries, and removes case-insensitive duplicates. A file enters the rule when its active `.editorconfig` section supplies at least one value.

Reviewed names use a second pipe-separated option:

```ini
meridian_forbidden_identifier_allowed_names = AllReferencesResolved
```

Allowed names use exact, case-sensitive comparison. Place each entry in the narrowest applicable `.editorconfig` section and record its supporting fact or provider term in an adjacent comment.

## Matching

Configured values use ordinal case-insensitive substring matching. This covers exact, starts-with, inner, and ends-with positions.

| Identifier | Result | Matched value |
| --- | --- | --- |
| `resolved` | Report | `resolved` |
| `ResolveFinalClassification` | Report | `resolve` |
| `matchResolvedState` | Report | `resolved` |
| `UnresolvedCount` | Report | `resolved` |
| `StatementReprepare` | Report | `prepare` |
| `DefaultJsonTypeInfoResolver` | Report | `resolve` |
| `Resolution` | Clear | Different spelling |
| `Preparation` | Clear | Different spelling |

The earliest match supplies the diagnostic message. The longest configured value wins when several values begin at the same position, so `resolved` identifies `resolved` ahead of `resolve`.

## Declaration scope

The rule covers:

- namespaces;
- classes, records, structs, interfaces, enums, and delegates;
- methods, local functions, properties, fields, events, and enum members;
- parameters, lambda parameters, and type parameters;
- local, `foreach`, catch, pattern, `out`, deconstruction, and query range variables;
- named tuple elements.

Generated code follows its schema or generator input. Test paths follow Meridian's production-rule exclusion. Referenced API members remain owned by their declaring library, so a call such as `command.Prepare()` stays clear while a locally declared `Prepare` method reports.

Source contracts own inherited names. The source interface or base declaration receives the diagnostic; implementations and overrides follow that declaration. The first source declaration owns a partial type or partial method name.

## Review sequence

1. State the observable behaviour or stored fact.
2. Identify its current domain or technical owner.
3. Establish the invariant or boundary that gives the declaration a reason to exist.
4. Choose keep, rename, move, merge, inline, or delete.
5. Use established domain vocabulary for a rename.
6. Add an exact allowed name when the current term expresses a proven fact or provider contract.

The rule ships as diagnostic-only. Source context determines the structural remedy.

## Examples

### Inline a redundant stage local

Reported:

```csharp
var resolved = context.Action;
var eventKind = resolved.EventKind;
```

Direct form:

```csharp
var eventKind = context.Action.EventKind;
```

### Review the owning operation

Reported:

```csharp
using var resolveOffers = sqlite.CreateCommand(sql);
resolveOffers.ExecuteNonQuery();
```

The review follows the SQL effect and the enclosing operation. A one-use command can remain short inside that owner, be inlined, or receive established state vocabulary when the name adds useful meaning.

### Retain a proven result fact

Reported and reviewed:

```csharp
public sealed record MatchReplayContentValidationResult(
    bool AllReferencesResolved,
    IReadOnlyList<MatchReplayContentReference> UnresolvedReferences);
```

`AllReferencesResolved` records the terminal result of reference validation. Its exact allowed-name entry retains that fact after review.

### Keep referenced provider members with their owner

Clear:

```csharp
command.Prepare();
```

The SQLite provider owns the referenced member name.
