# MER0033

## Summary

`MER0033` flags heavy multi-line lambdas inside LINQ and query-style fluent calls.

## Intent

Query lambdas stay reviewable when selection, filtering, and value construction fit inside a small expression. Larger inline query branches benefit from a named query step or helper.

## What It Reports

Reports nested query work inside a query lambda:

```csharp
return vacancies
    .SelectMany(vacancy => managers
        .Where(manager => manager.Status == "available")
        .Select(manager => {
            var score = Score(manager, vacancy);
            return new Candidate(manager, vacancy, score);
        }))
    .FirstOrDefault();
```

Reports multi-statement value construction inside a query lambda:

```csharp
return values
    .Select(value => {
        var id = value + 1;
        var label = id.ToString();
        return new Projection(
            id,
            label);
    })
    .ToArray();
```

Reports factory-style returns after local staging:

```csharp
return values
    .Select(value => {
        var id = value + 1;
        var label = id.ToString();
        return ProjectionFactory.Create(
            id,
            label);
    })
    .ToArray();
```

## Allowed Patterns

Small projections:

```csharp
return values
    .Select(value => new Projection(value))
    .ToArray();
```

Short statement lambdas:

```csharp
return values.Select(value => {
    var adjusted = value + 1;
    return adjusted;
}).ToArray();
```

## Preferred Refactor

1. Name the nested query branch.
2. Move statement-body value construction into a helper when it spans several lines.
3. Keep the fluent chain focused on query composition.

## Edge Cases

- Generated code is skipped.
- The lambda must span at least seven lines.
- The rule applies to LINQ and query-style operators on `IEnumerable<T>`, `IQueryable<T>`, and related query-like interfaces.
- The matcher requires LINQ or query-like receiver types.
- Statement-body matching covers object creation, factory calls, tuples, and record `with` returns after local staging.
