# MER0061

## Summary

`MER0061` flags `ZipFile.OpenRead` and `ZipArchiveEntry.Open` calls inside asynchronous methods, local functions, and anonymous functions.

## Intent

File-backed ZIP opening can block the caller. The asynchronous APIs preserve the surrounding asynchronous I/O boundary and accept cancellation tokens.

The rule uses API identity and asynchronous scope. `ZipArchiveEntry` backing-stream provenance remains a call-site review.

## What It Reports

```csharp
using var archive = ZipFile.OpenRead(sourcePath);
using var stream = entry.Open();
```

## What It Allows

- `ZipFile.OpenReadAsync` and `ZipArchiveEntry.OpenAsync`.
- Synchronous ZIP creation and writing code.
- Synchronous methods that deliberately own synchronous archive work.

## Preferred Refactor

Await the corresponding asynchronous opening API and pass the operation cancellation token.
