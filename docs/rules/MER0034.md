# MER0034

## Summary

`MER0034` flags direct ordinal `string.Equals`, instance `Equals`, and instance `Contains` calls that pass `StringComparison.Ordinal` or `StringComparison.OrdinalIgnoreCase`.

## Intent

Shared string comparison helpers keep null handling and ordinal comparison behavior consistent across in-memory code.

## What It Reports

Reports static ordinal equality:

```csharp
return string.Equals(value, other, StringComparison.Ordinal);
```

Preferred:

```csharp
return value.EqualsOrdinal(other);
```

Reports static ordinal ignore-case equality:

```csharp
return string.Equals(value, other, StringComparison.OrdinalIgnoreCase);
```

Preferred:

```csharp
return value.EqualsOrdinalIgnoreCase(other);
```

Reports instance ordinal contains:

```csharp
return value.Contains(token, StringComparison.Ordinal);
```

Preferred:

```csharp
return value.ContainsOrdinal(token);
```

Reports instance ordinal ignore-case contains:

```csharp
return value.Contains(token, StringComparison.OrdinalIgnoreCase);
```

Preferred:

```csharp
return value.ContainsOrdinalIgnoreCase(token);
```

## Covered APIs

The matcher targets ordinal `Equals` and `Contains` calls with a shared helper equivalent:

- `string.Equals(value, other, StringComparison.Ordinal)`
- `string.Equals(value, other, StringComparison.OrdinalIgnoreCase)`
- `value.Equals(other, StringComparison.Ordinal)`
- `value.Equals(other, StringComparison.OrdinalIgnoreCase)`
- `value.Contains(token, StringComparison.Ordinal)`
- `value.Contains(token, StringComparison.OrdinalIgnoreCase)`

Out-of-scope APIs remain on their existing call sites:

- `StringExtensions.cs`
- analyzer implementation files
- query-translated predicates
- expression-tree predicates
- culture-aware comparisons
- assertion helper overloads
- `StartsWith`, `EndsWith`, and `IndexOf`

## Preferred Refactor

Use the matching shared extension:

| Direct call | Shared helper |
| --- | --- |
| `string.Equals(value, other, StringComparison.Ordinal)` | `value.EqualsOrdinal(other)` |
| `string.Equals(value, other, StringComparison.OrdinalIgnoreCase)` | `value.EqualsOrdinalIgnoreCase(other)` |
| `value.Equals(other, StringComparison.Ordinal)` | `value.EqualsOrdinal(other)` |
| `value.Equals(other, StringComparison.OrdinalIgnoreCase)` | `value.EqualsOrdinalIgnoreCase(other)` |
| `value.Contains(token, StringComparison.Ordinal)` | `value.ContainsOrdinal(token)` |
| `value.Contains(token, StringComparison.OrdinalIgnoreCase)` | `value.ContainsOrdinalIgnoreCase(token)` |
