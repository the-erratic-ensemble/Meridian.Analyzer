# MER0059

## Summary

`MER0059` flags known `IndexOf`, `FindIndex`, and `BinarySearch` results that reach an index or range use without a visible miss guard.

## Intent

Ordinary searches return `-1` for a miss. Binary search returns a negative encoded insertion position. Neither result is a valid ordinary index until its state is handled.

## What It Reports

Reports:

```csharp
var index = text.IndexOf(marker, StringComparison.Ordinal);
return text[index..];
```

## What It Allows

- A negative-result guard before the index use.
- A valid-result branch such as `index >= 0`.
- The `~index` conversion used to decode a negative `BinarySearch` result.

## Preferred Refactor

Handle the miss branch immediately after the search and keep the valid index path separate.
