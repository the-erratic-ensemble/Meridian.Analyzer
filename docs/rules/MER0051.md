# MER0051

## Summary

`MER0051` flags async lambdas and anonymous methods converted to void-returning delegates.

## Intent

An async void callback has no task for its caller to await. Completion and failures can leave the callback owner without an observable outcome.

## What It Reports

Reports:

```csharp
Action save = async () => await SaveAsync();
```

## What It Allows

- A task-returning delegate such as `Func<Task>` or `Func<T, Task>`.
- An async anonymous function directly attached to an event.

## Preferred Refactor

Change the callback contract to return `Task` or `ValueTask`, then await or otherwise own the returned work.
