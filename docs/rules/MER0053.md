# MER0053

## Summary

`MER0053` flags a signed integral `Math.Abs` result used directly as the left operand of `%`.

## Intent

The minimum signed value has no positive counterpart in the same type. `Math.Abs` can throw before the remainder is calculated.

## What It Reports

Reports:

```csharp
var bucket = Math.Abs(value) % bucketCount;
```

## What It Allows

- Floating-point and decimal `Math.Abs` overloads.
- A remainder calculated before a bounded `Math.Abs` call.

## Preferred Refactor

Use a positive-remainder helper that handles the complete signed range and states the divisor contract.
