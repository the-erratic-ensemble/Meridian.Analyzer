# MER0045

## Summary

`MER0045` flags a broad catch around awaited work that receives a `CancellationToken` when the handler converts cancellation into an ordinary failure path.

## Intent

Cancellation is a control signal for request completion and coordinated shutdown. Keeping `OperationCanceledException` as cancellation preserves that signal across method boundaries.

## What It Reports

The rule targets `catch (Exception ...)` and catch-all clauses whose directly protected `try` block contains an awaited invocation receiving a `CancellationToken`.

The catch is reported when it has no visible cancellation-preserving shape:

- a preceding `OperationCanceledException` catch that rethrows
- a filter that excludes `OperationCanceledException`
- a rethrow of the caught exception or a cancellation-specific type check that rethrows

## What It Allows

- A dedicated cancellation catch followed by an ordinary failure catch.
- `when (exception is not OperationCanceledException)` filters.
- A broad handler that rethrows its caught exception.
- A handler that checks the caught exception’s type and rethrows it.

## Examples

### Conversion Into an Ordinary Failure

Incorrect:

```csharp
try {
    await HandleRequestAsync(request, lifetimeToken);
}
catch (Exception exception) {
    return InternalError(exception.Message);
}
```

Correct:

```csharp
try {
    await HandleRequestAsync(request, lifetimeToken);
}
catch (OperationCanceledException) {
    throw;
}
catch (Exception exception) {
    return InternalError(exception.Message);
}
```

### Cancellation Filter

```csharp
try {
    await WorkAsync(cancellationToken);
}
catch (Exception exception) when (exception is not OperationCanceledException) {
    LogFailure(exception);
}
```

## Current Analysis Scope

The initial proof resolves cancellation-token argument types and examines the directly protected try block. Nested try blocks and asynchronous work hidden inside local functions or lambdas remain separate analysis boundaries.

## Preferred Refactor

Keep cancellation handling in a dedicated path and let ordinary exception handling process ordinary failures.
