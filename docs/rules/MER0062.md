# MER0062

## Summary

`MER0062` flags record class construction with at least three supplied arguments when one or more arguments are positional.

## Intent

Named arguments keep values tied to the record members they populate. This makes wide projections and payload construction easier to review when fields are added or reordered.

## What It Reports

Reports:

```csharp
return new RuntimeMetadata(
    reader.GetString(0),
    reader.GetInt32(1),
    reader.GetString(2));
```

## What It Allows

- Record class construction with every argument named.
- Explicit and target-typed record class construction.
- Record construction with fewer than three supplied arguments.
- Record struct construction.
- Ordinary class and struct construction.

## Preferred Refactor

Name each argument at the construction site:

```csharp
return new RuntimeMetadata(
    CareerId: reader.GetString(0),
    SimulationDay: reader.GetInt32(1),
    SeasonKey: reader.GetString(2));
```

## Analysis Scope

The analyzer resolves the constructor symbol and checks whether its containing type is a record class. Test paths are outside the rule scope. A single diagnostic covers each construction with at least three supplied arguments containing a positional argument.
