# MER0054

## Summary

`MER0054` flags a standalone standard dictionary `TryGetValue` call when its out value is read later.

## Intent

The out value receives `default` for a missing key. The Boolean result records whether the value was present and keeps that distinction visible.

## What It Reports

Reports:

```csharp
values.TryGetValue(key, out var value);
return value;
```

## What It Allows

- Branches and expressions that consume the Boolean result.
- An explicit default-on-missing operation such as `GetValueOrDefault`.
- A discarded out value that is never read later.

## Preferred Refactor

Branch on the Boolean when presence matters, or use a named defaulting operation when default-on-missing is the contract.
