# MER0052

## Summary

`MER0052` flags known structural mutations of a tracked standard collection while that same collection is the direct `foreach` source.

## Intent

List, dictionary, set, queue, stack, linked-list, and collection enumerators can reject structural changes made during enumeration.

## What It Reports

Reports:

```csharp
foreach (var item in items)
    items.Remove(item);
```

## What It Allows

- A materialized source such as `items.ToArray()` or `items.ToList()`.
- Collection types and members outside the rule's standard mutation table.
- Concurrent collection enumeration, which has different runtime behavior.

## Preferred Refactor

Enumerate a snapshot, collect the changes for a later pass, or use an API designed for the required mutation.
