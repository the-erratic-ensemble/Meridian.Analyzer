# MER0037

## Summary

`MER0037` flags `ArrayPool<T>.Rent` results without exactly one return to the same pool or a disposable rental-owner transfer.

## Intent

Array-pool buffers carry a manual lifetime. Matching the pool instance preserves the rental contract when a method has more than one pool available.

## What It Reports

Reports `ArrayPool<T>.Rent` calls whose returned array has no visible ownership action in the containing method.

The direct matcher follows these shapes:

- A rental assigned to a local variable through a declaration or simple assignment.
- A subsequent `ArrayPool<T>.Return` call whose first argument is that local.
- The same pool receiver for both `Rent` and `Return`, such as the same `pool` local or `ArrayPool<byte>.Shared` property.
- The next assignment to the local as the boundary between two rental lifetimes.

A rental with no local target is reported at the `Rent` call. A local rental is reported when the containing method contains zero or multiple matching returns before the next assignment.

## What It Allows

- One return to the same pool receiver for each direct local rental.
- A direct transfer into a disposable type whose name ends in `Rental` and which implements `IDisposable` or `IAsyncDisposable`.
- A `clearArray` argument on `Return`, when the pool and rented local still match.
- Test paths, which are outside the production ownership rule.

## Examples

### Direct Return

Incorrect:

```csharp
var buffer = ArrayPool<byte>.Shared.Rent(size);
Use(buffer);
```

Correct:

```csharp
var buffer = ArrayPool<byte>.Shared.Rent(size);
try {
    Use(buffer);
}
finally {
    ArrayPool<byte>.Shared.Return(buffer);
}
```

### Matching the Pool Instance

Incorrect:

```csharp
var pool = ArrayPool<byte>.Shared;
var otherPool = ArrayPool<byte>.Create();
var buffer = pool.Rent(size);

otherPool.Return(buffer);
```

Correct:

```csharp
var pool = ArrayPool<byte>.Shared;
var buffer = pool.Rent(size);

pool.Return(buffer);
```

### Reassignment

Each rental receives its own return before the local is reused:

```csharp
var buffer = pool.Rent(firstSize);
try {
    UseFirst(buffer);
}
finally {
    pool.Return(buffer);
}

buffer = pool.Rent(secondSize);
try {
    UseSecond(buffer);
}
finally {
    pool.Return(buffer);
}
```

### Disposable Rental Owner

The initial transfer boundary recognizes a direct rental argument to a disposable `*Rental` type:

```csharp
using var rental = new ByteRental(
    ArrayPool<byte>.Shared.Rent(size));
```

The owner is responsible for returning the array exactly once during disposal.

## Current Analysis Scope

The first proof follows direct local assignments and direct constructor transfer. Field-backed buffers, `ref` transfers, and helper methods that carry rental ownership require an explicit owner contract or a deeper value-flow boundary. Those shapes are separate from the direct local return pattern.

## Preferred Refactor

Keep the rental and its return in the same ownership scope. Use `try` and `finally` when work can throw, match the exact pool instance, and transfer directly to a disposable rental owner when another object must retain the buffer.
