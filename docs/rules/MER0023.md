# MER0023

## Summary

`MER0023` flags task-returning work whose completion and failure are not obviously observed.

## Intent

Discarded tasks and genuinely detached `Task.Run` work can hide failures and outlive their intended runtime boundary. The rule follows task ownership rather than treating every `Task.Run` call as detached.

Cancellation-token propagation is outside this rule. ASP.NET controller cancellation remains owned by `MER0009`, route cancellation is owned by `MER0035`, and downstream token forwarding is covered by `CA2016`.

## What It Reports

Reports outside tests:

- discarded task-returning calls such as `_ = PublishAsync()`
- `Task.Run(...)` used as a statement or discard
- `Task.Run(...)` stored in a local that is never awaited, returned, aggregated, or passed to an `IBackgroundTaskOwner`

The rule uses semantic return types for discarded calls. A method merely ending in `Async` does not trigger the rule unless it returns `Task` or `ValueTask`.

## What It Allows

- `await Task.Run(...)`
- returning `Task.Run(...)` to the caller
- local tasks later observed through `await`, `return`, `Task.WhenAll`, or `Task.WhenAny`
- task collections whose elements are created with `Task.Run` and later passed to `Task.WhenAll` or `Task.WhenAny`
- tasks passed to a type implementing `IBackgroundTaskOwner`

## Examples

Incorrect:

```csharp
_ = _eventPublisher.PublishAsync(new ReportCompleted(reportId));
```

Correct:

```csharp
await _eventPublisher.PublishAsync(
    new ReportCompleted(reportId),
    cancellationToken);
```

Incorrect:

```csharp
var task = Task.Run(() => Render(reportId));
```

Correct:

```csharp
var task = Task.Run(() => Render(reportId));
await task;
```

Correct parallel ownership:

```csharp
var tasks = reports
    .Select(report => Task.Run(() => Render(report.Id), cancellationToken))
    .ToArray();

await Task.WhenAll(tasks);
```

## Preferred Refactor

Await or return foreground work. For intentionally longer-lived work, pass the task to an `IBackgroundTaskOwner` implementation that owns cancellation, completion, and failure observation.
