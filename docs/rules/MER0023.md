# MER0023

## Summary

`MER0023` flags task-returning work whose completion and failure lack an obvious observer.

## Intent

Task ownership makes failures and lifetimes visible. Discarded tasks and genuinely detached `Task.Run` work can hide failures and outlive their intended runtime boundary. The analyzer determines whether completion is owned by the surrounding code or an explicit background-task owner.

Cancellation-token propagation belongs to `MER0009` for ASP.NET controllers, `MER0035` for routes, and `CA2016` for downstream token forwarding.

## What It Reports

Reports outside tests:

- discarded task-returning calls such as `_ = PublishAsync()`
- `Task.Run(...)` used as a statement or discard
- `Task.Run(...)` stored in a local that is never awaited, returned, aggregated, or passed to an `IBackgroundTaskOwner`

The rule uses semantic return types for discarded calls. A method ending in `Async` triggers the rule only when it returns `Task` or `ValueTask`.

## What It Allows

- `await Task.Run(...)`
- returning `Task.Run(...)` to the caller
- local tasks later observed through `await`, `return`, or `Task.WhenAll`
- task collections whose elements are created with `Task.Run` and later passed to `Task.WhenAll`
- tasks passed to a type implementing `IBackgroundTaskOwner`

## Examples

Incorrect:

```csharp
_ = _eventPublisher.PublishAsync(new ReportCompleted(reportId));
```

Correct:

```csharp
await _eventPublisher.PublishAsync(
    new ReportCompleted(reportId),
    cancellationToken);
```

Incorrect:

```csharp
var task = Task.Run(() => Render(reportId));
```

Correct:

```csharp
var task = Task.Run(() => Render(reportId));
await task;
```

Correct parallel ownership:

```csharp
var tasks = reports
    .Select(report => Task.Run(() => Render(report.Id), cancellationToken))
    .ToArray();

await Task.WhenAll(tasks);
```

## Preferred Refactor

Await or return foreground work. For intentionally longer-lived work, pass the task to an `IBackgroundTaskOwner` implementation that owns cancellation, completion, and failure observation.
