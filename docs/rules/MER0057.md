# MER0057

## Summary

`MER0057` flags `Math.Round` and `MathF.Round` overloads that omit `MidpointRounding`.

## Intent

The overloads default to midpoint-to-even behavior. An explicit mode makes half-value behavior reviewable at the call site.

## What It Reports

Reports:

```csharp
var rounded = Math.Round(value, 2);
```

## What It Allows

- Any overload that receives `MidpointRounding.ToEven` or another explicit mode.
- Other mathematical operations without a midpoint policy.

## Preferred Refactor

Add `MidpointRounding.ToEven` to preserve the default behavior, or choose the mode required by the value contract.
