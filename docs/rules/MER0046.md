# MER0046

## Summary

`MER0046` flags generic and non-generic `TaskCompletionSource` construction when its creation options omit `TaskCreationOptions.RunContinuationsAsynchronously`.

## Intent

Completing a task can run its continuations inline. Asynchronous continuation dispatch keeps waiter code outside the completion call’s critical section and reduces re-entrancy through the completing thread.

## What It Reports

The rule reports:

- parameterless `TaskCompletionSource` construction
- construction with `TaskCreationOptions.None`
- option expressions whose flags omit `RunContinuationsAsynchronously`

Bitwise combinations and constant option expressions are inspected for the flag.

## What It Allows

- `TaskCreationOptions.RunContinuationsAsynchronously`.
- A bitwise combination containing that option.
- Generic and non-generic sources using an overload that preserves state and carries the option.

## Examples

### Non-Generic Source

Incorrect:

```csharp
var signal = new TaskCompletionSource();
```

Correct:

```csharp
var signal = new TaskCompletionSource(
    TaskCreationOptions.RunContinuationsAsynchronously);
```

### Generic Source With State

```csharp
var signal = new TaskCompletionSource<DrainResult>(
    state: this,
    creationOptions: TaskCreationOptions.RunContinuationsAsynchronously);
```

## Current Analysis Scope

The analyzer resolves the framework type and examines creation-option arguments. It recognizes the enum member, bitwise combinations, and constant values. Runtime option values held in non-constant locals require a visible option expression at the construction site.

## Preferred Refactor

Supply `TaskCreationOptions.RunContinuationsAsynchronously` on every task-completion source used for coordination or signaling.
