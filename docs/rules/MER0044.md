# MER0044

## Summary

`MER0044` flags string-key dictionaries, string sets, and selected LINQ equality operations whose comparer is implicit.

## Intent

Equality and hashing policy affects identifiers, grouping, de-duplication, and set operations. An explicit `IEqualityComparer<string>` records the intended case and equality semantics at the boundary.

## What It Reports

The rule covers:

- `Dictionary<string, TValue>` construction with an implicit string equality comparer
- `HashSet<string>` construction with an implicit string equality comparer
- `ToDictionary`, `ToHashSet`, and `ToLookup`
- `Distinct` and `GroupBy`
- `Union`, `Intersect`, and `Except`

The LINQ operation is reported when the relevant element, key, or grouping key type is `string` and the comparer overload is absent.

## What It Allows

- `StringComparer.Ordinal` and `StringComparer.OrdinalIgnoreCase`.
- `EqualityComparer<string>.Default` or a custom `IEqualityComparer<string>` supplied explicitly.
- Operations whose relevant type is another type.
- A comparer parameter explicitly supplied as a named or positional argument.

## Examples

### String-Key Dictionary

Incorrect:

```csharp
var values = new Dictionary<string, int>();
```

Correct:

```csharp
var values = new Dictionary<string, int>(StringComparer.Ordinal);
```

### Distinct Values

Incorrect:

```csharp
var factors = decisionFactors.Distinct().ToArray();
```

Correct:

```csharp
var factors = decisionFactors
    .Distinct(StringComparer.Ordinal)
    .ToArray();
```

### Grouping

Incorrect:

```csharp
var groups = rows.GroupBy(row => row.EntityKind);
```

Correct:

```csharp
var groups = rows.GroupBy(row => row.EntityKind, StringComparer.Ordinal);
```

## Analysis Scope

The analyzer resolves `System.Collections.Generic.Dictionary` and `HashSet` construction plus the selected `System.Linq.Enumerable` methods. Null and default comparer expressions represent the default policy and remain reportable.

## Preferred Refactor

Choose the equality comparer from the data contract and pass it at the collection or LINQ operation that establishes equality semantics.
