# MER0056

## Summary

`MER0056` flags generic `Enum.Parse<TEnum>` and `Enum.TryParse<TEnum>` calls for ordinary enums when a local `Enum.IsDefined` proof is absent.

## Intent

Enum parsing accepts numeric text. A numeric value can have the enum type while matching no declared member.

## What It Reports

Reports:

```csharp
return Enum.Parse<Mode>(text, true);
```

## What It Allows

- A direct `Enum.IsDefined` check in the parsed value's immediate flow.
- A `TryParse` condition that combines parse success with `Enum.IsDefined`.
- Enums marked with `FlagsAttribute`, which need different combined-value validation.

## Preferred Refactor

Pair parse success with defined-value validation before returning or storing the ordinary enum value.
