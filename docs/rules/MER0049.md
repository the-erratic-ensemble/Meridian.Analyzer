# MER0049

## Summary

`MER0049` flags `==` and `!=` when both operands are arrays.

## Intent

Array operators compare object references. Content equality needs an explicit sequence comparison, while identity needs an explicit reference comparison.

## What It Reports

Reports:

```csharp
if (expected == actual)
    return true;
```

## What It Allows

- Comparisons where either operand is the `null` literal.
- `SequenceEqual` or span comparisons for contents.
- `ReferenceEquals` for object identity.

## Preferred Refactor

Choose content or identity semantics at the comparison site and use the API that states that choice.
