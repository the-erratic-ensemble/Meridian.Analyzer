# MER0055

## Summary

`MER0055` flags multi-byte numeric `BitConverter` conversions without an enclosing `BitConverter.IsLittleEndian` branch.

## Intent

BitConverter follows machine byte order. Stable binary data needs a declared little-endian or big-endian contract.

## What It Reports

Reports:

```csharp
var value = BitConverter.ToUInt32(bytes, 0);
```

## What It Allows

- `BinaryPrimitives.Read*Endian` and `Write*Endian` methods.
- Numeric conversions inside a `BitConverter.IsLittleEndian` branch whose two paths contain explicit byte-order operations.
- Single-byte conversions and bit reinterpretation helpers.

## Preferred Refactor

Use a `BinaryPrimitives` method whose name states the chosen byte order at the conversion site.
