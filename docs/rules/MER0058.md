# MER0058

## Summary

`MER0058` flags a nonconstant array dimension in an explicit `stackalloc` expression when no local fixed ceiling is visible.

## Intent

Runtime stack allocation can exhaust a thread stack when input size is large or untrusted.

## What It Reports

Reports:

```csharp
Span<byte> buffer = stackalloc byte[byteCount];
```

## What It Allows

- Constant dimensions.
- A conditional or earlier terminating guard that caps the same local value.
- Pooled or heap storage for sizes outside the chosen stack ceiling.

## Preferred Refactor

Keep small bounded buffers on the stack and route larger values to pooled or heap storage.
