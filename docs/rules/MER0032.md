# MER0032

## Summary

`MER0032` flags conditional LINQ projections that clone a record and update multiple or nested members inline.

## Intent

Record rewrites carry business rules. When a `.Select` projection handles selection, record cloning, and nested member updates in one expression, the rule becomes harder to review.

## What It Reports

Reports:

```csharp
return sheets
    .Select(sheet => sheet.ClubId == managedClubId
        ? sheet with {
            StartingFootballerIds = sheet.StartingFootballerIds
                .Select(id => id == offFootballerId ? onFootballerId : id)
                .ToArray(),
            RoleAssignments = sheet.RoleAssignments
                .Where(assignment => assignment.FootballerId != offFootballerId)
                .Append(new RoleAssignment(onFootballerId, roleId))
                .ToArray(),
        }
        : sheet)
    .ToArray();
```

```csharp
return footballers
    .Select(footballer => footballer.CurrentClubId == clubId
        ? footballer with {
            AvailabilityStatus = "available",
            UnavailableUntil = null,
            AvailabilityReason = null,
        }
        : footballer)
    .ToArray();
```

```csharp
return clubs
    .Select(club => club.Id == clubId && club.Finance is not null
        ? club with {
            Finance = club.Finance with {
                CashBalance = subtract
                    ? Math.Max(0, club.Finance.CashBalance - amount)
                    : club.Finance.CashBalance + amount,
            },
        }
        : club)
    .ToArray();
```

```csharp
return clubs
    .Select(club => club.Id == formerClubId
        ? club with {
            Finance = club.Finance! with {
                CashBalance = club.Finance!.CashBalance + amount,
            },
        }
        : club.Id == destinationClubId
            ? club with {
                Finance = club.Finance! with {
                    CashBalance = Math.Max(0, club.Finance!.CashBalance - amount),
                },
            }
            : club)
    .ToArray();
```

## Allowed Patterns

Simple record updates:

```csharp
return items
    .Select(item => item.Id == id
        ? item with { Status = "done" }
        : item)
    .ToArray();
```

Single child collection rewrites:

```csharp
return sheets
    .Select(sheet => sheet.ClubId == managedClubId
        ? sheet with {
            StartingFootballerIds = sheet.StartingFootballerIds
                .Select(id => id == offFootballerId ? onFootballerId : id)
                .ToArray(),
        }
        : sheet)
    .ToArray();
```

Single-member updates:

```csharp
return sheets
    .Select(sheet => sheet.ClubId == managedClubId
        ? sheet with {
            StartingFootballerIds = ReplaceFootballer(sheet.StartingFootballerIds),
        }
        : sheet)
    .ToArray();
```

## Examples

Problem:

```csharp
return input.TeamSheets
    .Select(sheet => sheet.ClubId == managedClubId
        ? sheet with {
            StartingFootballerIds = ReplaceFootballer(sheet.StartingFootballerIds),
            RoleAssignments = ReplaceRoleAssignment(sheet.RoleAssignments),
        }
        : sheet)
    .ToArray();
```

Preferred:

```csharp
return input.TeamSheets
    .Select(sheet => sheet.ClubId == managedClubId
        ? ApplySubstitution(sheet, offFootballerId, onFootballerId, roleId)
        : sheet)
    .ToArray();
```

## Preferred Refactor

1. Move the record clone into a named helper.
2. Stage each member update in a local with a domain name.
3. Keep the `.Select` projection focused on choosing the item to update.

## Edge Cases

- Generated code is skipped.
- The rule applies to conditional expressions used as `.Select` lambda bodies.
- The true or false branch must be a multi-line record `with` expression.
- The initializer must update at least two members, contain a multi-line nested record `with` expression, or choose between multiple multi-line record `with` branches.
