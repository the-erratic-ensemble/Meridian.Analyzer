# MER0050

## Summary

`MER0050` flags instance `GetHashCode`, `StringComparer.GetHashCode`, and `HashCode.Combine` calls outside equality hash implementations.

## Intent

Runtime hash codes can vary between processes, runtime versions, and implementations. Stable IDs, persisted values, protocol data, and deterministic draws need an explicit stable hash contract.

## What It Reports

Reports:

```csharp
var seed = input.GetHashCode();
```

## What It Allows

- An override of `object.GetHashCode`.
- An implementation of `IEqualityComparer<T>.GetHashCode`.

## Preferred Refactor

Use an explicit stable encoding and cryptographic or otherwise documented stable hash when the value crosses a process, persistence, or determinism boundary.
