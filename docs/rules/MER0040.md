# MER0040

## Summary

`MER0040` flags `JsonElement` values derived from a locally owned `JsonDocument` when they return, enter a member or collection, or are captured by a callback in a method with document disposal ownership.

## Intent

`JsonElement` normally refers to storage owned by its parent document. `Clone` gives a retained element an independent lifetime.

## What It Reports

Reports an element derived from a locally disposed `JsonDocument` when the value reaches an escape sink. The initial origin tracker follows:

- `document.RootElement`.
- `GetProperty(...)` results.
- `EnumerateArray()` values.
- `EnumerateObject()` property values through `JsonProperty.Value`.
- Local aliases, simple assignments, array indexing, and conditional expressions built from those values.

The initial escape sinks are:

- A method return.
- A field or property assignment.
- An element assignment or insertion through methods such as `Add`, `Insert`, `Enqueue`, `Push`, `Set`, `SetValue`, or `TryAdd`.
- A lambda captured by callback-style methods such as `Add`, `ContinueWith`, `Invoke`, `Post`, `Queue`, `Register`, or `Subscribe`.

The document must have local disposal ownership through a `using` declaration, a `using` statement, or a later explicit `Dispose` call for the rule to activate. Disposal ownership is established at the containing-method level.

## What It Allows

- `JsonElement.Clone()` at the boundary where the element leaves the document scope.
- Scalar and string extraction performed while the document remains alive.
- Local element aliases consumed within the document lifetime.
- A complete `JsonDocument` returned or assigned to a longer-lived owner, with that owner responsible for disposal.
- Direct `JsonDocument.Parse(...).RootElement` construction, which belongs to `CA2026`.

## Examples

### Returning the Root Element

Incorrect:

```csharp
public JsonElement ReadRoot(string payload) {
    using var document = JsonDocument.Parse(payload);
    return document.RootElement;
}
```

Correct:

```csharp
public JsonElement ReadRoot(string payload) {
    using var document = JsonDocument.Parse(payload);
    return document.RootElement.Clone();
}
```

### Returning a Property

Incorrect:

```csharp
public JsonElement ReadValue(string payload) {
    using var document = JsonDocument.Parse(payload);
    var value = document.RootElement.GetProperty("value");
    return value;
}
```

Correct:

```csharp
public JsonElement ReadValue(string payload) {
    using var document = JsonDocument.Parse(payload);
    var value = document.RootElement.GetProperty("value");
    return value.Clone();
}
```

### Retaining a Collection

Incorrect:

```csharp
public IReadOnlyList<JsonElement> ReadItems(string payload) {
    using var document = JsonDocument.Parse(payload);
    var items = new List<JsonElement>();
    foreach (var item in document.RootElement.EnumerateArray())
        items.Add(item);
    return items;
}
```

Correct:

```csharp
public IReadOnlyList<JsonElement> ReadItems(string payload) {
    using var document = JsonDocument.Parse(payload);
    var items = new List<JsonElement>();
    foreach (var item in document.RootElement.EnumerateArray())
        items.Add(item.Clone());
    return items;
}
```

### Callback Capture

Incorrect:

```csharp
using var document = JsonDocument.Parse(payload);
callbacks.Register(() => Process(document.RootElement));
```

Correct:

```csharp
using var document = JsonDocument.Parse(payload);
var snapshot = document.RootElement.Clone();
callbacks.Register(() => Process(snapshot));
```

### Scalar Consumption

Scalar extraction keeps the result independent from the document storage:

```csharp
using var document = JsonDocument.Parse(payload);
return document.RootElement.GetProperty("id").GetString();
```

## Current Analysis Scope

The direct proof covers locally disposed documents, the listed element origins, local aliases, and direct escape syntax. The current method-level disposal check does not follow control-flow ordering between an explicit `Dispose` call and each escape sink, so a sink that appears before a later `Dispose` call can still be reported. Collection lifetime, whole-document owner contracts, method-group callbacks, and helper methods that retain an element require a more explicit interprocedural ownership boundary.

## Preferred Refactor

Clone immediately before returning, storing, inserting, or capturing an element. Keep scalar extraction inside the document scope, and transfer the complete document only when a longer-lived owner clearly controls its disposal.
