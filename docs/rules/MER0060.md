# MER0060

## Summary

`MER0060` flags raw `MemoryStream.GetBuffer()` arrays that return, enter a member, reach a `byte[]` payload parameter, or enter storage through a `byte[]` parameter before a written range is applied.

## Intent

The backing array can have capacity beyond `MemoryStream.Length`. A complete-array payload can therefore include unwritten bytes.

## What It Reports

Reports:

```csharp
return stream.GetBuffer();
```

## What It Allows

- `AsSpan(offset, length)` and `AsMemory(offset, length)` uses.
- `ArraySegment`, span, and memory construction with explicit offset and count.
- Local length, rank, and element inspection.
- A local buffer whose later uses all carry an explicit range.

## Preferred Refactor

Use a range-bearing view for zero-copy work or `ToArray()` when the consumer needs an owned exact-size array.
